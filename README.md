# KABAN GAMES

Игры для компании: интерфейс на React + Vite и React Router, сервер лобби на FastAPI. Сначала создайте лобби или войдите по коду, затем ведущий выбирает игру внутри лобби; участники переходят в неё автоматически. Ведущий создаёт комнату, игроки подключаются по четырёхбуквенному коду. В детективном деле «Последний сеанс» каждый участник может открывать общие улики, а ведущий отправляет итоговую версию. В остальных играх ведущий выбирает карточки и показывает ответы.

## Запуск через Docker

Нужны Docker Desktop и запущенный Docker Engine. В папке проекта:

```sh
docker compose up --build -d
```

Откройте http://localhost:8000. Чтобы игроки подключились с других устройств, откройте порт 8000 в локальной сети и используйте IP компьютера вместо localhost. Остановка: `docker compose down`. Посмотреть журнал: `docker compose logs -f`.

Для другого внешнего порта укажите переменную `PORT` перед запуском (например, `PORT=8080 docker compose up --build -d` в Linux/macOS или `$env:PORT=8080; docker compose up --build -d` в PowerShell).

Compose также запускает PostgreSQL и Redis во внутренней сети. PostgreSQL хранит аккаунты, профиль и сессии в томе `kaban-postgres`. Redis хранит кеш профилей до пяти минут и счётчики попыток входа. Гости могут играть по коду. Профиль даёт ник по умолчанию и выбор аватара для новых комнат.

На сервере с HTTPS прокси должен передавать исходный заголовок `Host`. Перед первой инициализацией PostgreSQL можно задать `POSTGRES_PASSWORD` в окружении Docker Compose. Сохраните выбранный пароль для последующих запусков. Для запуска без Compose аккаунтам нужны переменные `DATABASE_HOST`, `POSTGRES_USER`, `POSTGRES_DB`, `POSTGRES_PASSWORD` и `REDIS_URL`.

## Быстрое размещение

Проект подходит для хостинга, который запускает Dockerfile. Загрузите папку проекта в репозиторий, создайте на выбранном хостинге веб-сервис из этого репозитория и выберите сборку по Dockerfile. Сервис слушает переменную `PORT` (если она не задана — 8000). Проверка доступности: `GET /api/health`. Настройте HTTPS и откройте выданный хостингом адрес. Конкретные шаги зависят от выбранного сервиса.

На VPS с установленным Docker можно скопировать проект на сервер и выполнить `docker compose up --build -d`. Для домена и HTTPS поставьте перед приложением обратный прокси. Комнаты сохраняются в подключённом Docker volume и восстанавливаются после перезапуска. Не удаляйте volume `kaban-data`: без него пропадут комнаты, пока они активны (неактивные комнаты удаляются через 6 часов). Один экземпляр приложения рассчитан на один VPS.

## Разработка без Docker

Терминал 1:

```sh
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --port 8000
```

Терминал 2:

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес Vite из вывода команды. Запросы `/api` направляются на FastAPI. Сборка интерфейса: `npm run build` в папке `frontend`.

## Ограничения текущей версии

Максимум 16 участников в комнате. В лобби участники отмечают готовность, а ведущий ждёт всех перед запуском. Слово в «Крокодиле» показывается только ведущему. Закрытая или неактивная комната со временем удаляется, а комнаты сохраняются на диске и восстанавливаются при перезапуске сервера.

Детектив расширен до 20 материалов и пяти вопросов. Улики открываются по зависимостям (например, осмотр зала → экспертиза; камера и реестр → досмотр футляра). В блокноте можно сохранять личные заметки и получить подсказку. Три фотореалистичные иллюстрации созданы специально для вымышленного дела; карточки поддерживают увеличение снимков.


В разделе «Обсуждение» участники делятся версиями и аргументами. Каждый может изменить свою версию до окончания дела; после финала показаны ответы команды и правильные ответы. Личный блокнот остаётся на устройстве игрока.

Сетевые раунды: в восьми играх с вопросами каждый участник отвечает на своём устройстве, раунд длится до 30 секунд, а сервер начисляет очки. В «Закончи фразу» нужно минимум три участника: каждый пишет ответ, затем участники голосуют анонимно. За каждый голос автор получает 100 очков. Подключившиеся посреди раунда играют со следующего раунда. «Крокодил», «Правда или действие», «Две правды и одна ложь», «Безумный сценарист» и «Кто скорее?» поддерживают личные действия, ходы и голосование участников. В «Крокодиле» показывать жесты и говорить друг с другом нужно при личной встрече или через отдельный видеозвонок.


Добавлены «Шпион» (от четырёх участников: личные роли, вопросы, обсуждение и поиск шпиона) и «Реакция» (от двух участников: сигнал, ловушки и фальстарты). В шапке и вкладке используется оригинальный SVG-знак кабана. Одинаковые ники внутри комнаты запрещены.

В лобби и играх есть встроенная видеосвязь через VDO.Ninja: участник сам включает камеру с подтверждением, а постоянная панель остаётся подключённой при переходах между страницами. Для каждого лобби создаётся случайная комната с отдельным паролем. Микрофон отключён; для камеры нужен HTTPS и разрешение браузера; стабильность зависит от устройства, сети и VDO.Ninja.

В детективе доступны общие вкладки «Доска» и «Хронология». На доску можно закрепить изученные материалы, перемещать их и связывать подписанными нитями. Хронология хранит события команды с временем (или неизвестным временем), источником и автором. Изменения синхронизируются между участниками и сохраняются вместе с комнатой. После финального обвинения доска доступна только для чтения; новое дело начинает чистую доску.


## Codenames

Отдельная комната на две или три команды. Минимум капитан и агент в каждой команде (4 или 6 человек). С предателями — минимум три человека на команду (6 или 9 участников). Все подтверждают готовность перед запуском.

Словари: обычный — 3000 слов, Minecraft — 289, CS2 — 252, Dota 2 — 340. Поле 5×5 для двух команд (9/8 агентов), 6×6 для трёх (10/9/9). Всегда 7 мирных жителей и один убийца. Капитаны отправляют шифр в одно свободное текстовое поле. Количество открытий не ограничено. Соблюдение смысловых правил проверяют участники. Нарушение подтверждает ведущий или текущий капитан: следующий капитан получает бесплатное открытие своего слова.

У каждой команды по умолчанию 60 секунд на ход, включая подготовку шифра и угадывание. Ведущий может изменить время отдельно для каждой команды (0–3600 секунд; 0 — без таймера). Каждый новый ход получает полный лимит: остаток не переносится и не накапливается. По истечении времени ход переходит следующей команде. На штрафном открытии часы стоят. Убийца выводит команду из партии и публично открывает её агентов; остальные продолжают играть.

Секретные роли и ключ фильтруются сервером. Предатель видит агентов всех чужих команд и убийцу, но не своих агентов и мирных жителей. После финала раскрывается весь ключ. Подключившиеся посреди партии наблюдают до следующей.

Проверка правил, таймеров и скрытых данных: `python -m unittest discover -s tests -v`.


## Босс и Подрывник / Мировое господство

Оба режима доступны только как отдельные комнаты из каталога. Это сетевые игры для реальных участников: боты и имитация голосового чата из HTML-прототипов не используются. Встроенный текстовый чат работает на всех устройствах.

«Босс и Подрывник»: от 6 до 16 участников, чётное число; 3 раунда (по умолчанию 5 минут). Тайные роли, две изолированные комнаты и чаты, голосование за лидера, показ цвета, личная однократная проверка комиссара. Лидеры окончательно выбирают по одному игроку на обмен; переход происходит одновременно. Победа проверяется после третьего обмена. Камеры и общие реакции в этом режиме скрыты, чтобы не объединять комнаты.


Таймеры, действия и экономика проверяются сервером. Повторные и устаревшие запросы отклоняются. Состояние сохраняется вместе с комнатой, обновление страницы восстанавливает участие; присоединение посреди партии — в режиме наблюдателя. При уходе ключевого игрока хозяин комнаты может прервать партию и собрать участников заново.


## Обновление обычных режимов

Раунды выбираются из 5, 10, 15, 25, 50 и 100. Банки без повторов заданий внутри партии: викторина — 198, фильмы по эмодзи — 117, правда или фейк — 120, значения слов — 135, кино-викторина — 122, угадай фильм — 117. «Закончи фразу»: 148 начал; «Кто скорее?» — 127 вопросов (голосовать за себя нельзя). Викторина 18+ удалена из каталога и банка.

В викторинах правильный ответ даёт 100 очков и до 200 за скорость: бонус линейно уменьшается за 30 секунд. Время фиксирует сервер, учитывая задержку сети; повторное начисление исключено. В результатах видно количество очков за конкретный ответ. В эмодзи-раундах отвлекающие варианты по возможности не повторяются подряд.

«Угадай марку»: реальные локальные эмблемы, обычная и сложная маскировка. Пять вариантов: фрагмент, жалюзи, мозаика, силуэт и прорезь; один и тот же вариант не повторяется подряд. Сложность задаёт ведущий, маску выбирает сервер одинаково для всех. Для распространённых эмблем варианты ответа подбираются среди похожих форм. После окончания раунда показываются полный знак и название.

На подготовку трёх фактов — 120 секунд. В сценаристе каждый пишет свой текст (до 500 символов, 120 секунд), затем проводится анонимное голосование без голоса за себя. Выбранное продолжение добавляется к общей истории, авторы получают по 100 за голос. Можно выбрать до 100 частей истории.

В «Шпионе» игрок пишет собственный вопрос, отвечает текстом либо отмечает ответ голосом / в Discord. Есть общий чат и две минуты обсуждения; если все готовы, голосование начинается раньше. Встроенный голосовой канал не добавлен. Детектив в этом обновлении не менялся.

Для автомобильных заданий используется проверенный набор из 137 эмблем с графическим знаком. Словесные логотипы исключены из выпадения. Полные названия на комбинированных знаках закрываются или обрезаются до применения игровой маски, включая текст, нарисованный SVG-контурами. После раунда открывается оригинал. Правила областей хранятся в `backend/car_puzzles.json`.

Набор эмблем расширен до 210 марок. Добавлены 73 марки, включая отдельные SVG-символы и дополнительные редкие марки из открытого автомобильного каталога. Для Dacia, Acura, Infiniti, Mazda, Cupra, Hyundai, Tesla и Iran Khodro используются найденные готовые символы без текстовой подписи; остальные источники и области просмотра зафиксированы в манифестах. Картинки хранятся на сайте, внешние CDN во время игры не нужны.

## Приватное «Мировое господство»

Для новой партии нужен отдельный ведущий (хозяин комнаты) и минимум две страны. У страны до трёх игроков. На первом этапе каждый получает только свою панель. Чужие деньги, доходы, города, щиты, ракеты и исследования не отправляются клиентам на любом этапе, включая финал. Имена стран остаются в справочнике целей без характеристик. Журнал действий тоже приватный. Общая статистика поступает только ведущему и только на третьем этапе; он озвучивает её или публикует текстовую сводку.

Второй этап — личные переговоры: приглашение, согласие адресата, закрытый разговор между двумя странами. Текст сообщений и параметры голосового канала недоступны посторонним странам и ведущему. Общего чата стран нет. Своя команда может общаться отдельно. Длительность переговоров выбирается в лобби (1–15 минут).

В лобби ведущий выбирает режим «Без голоса» или «С голосом». Во втором режиме встроен VDO.Ninja без камеры: отдельный канал своей команды, отдельный канал каждой принятой встречи и канал сводки на третьем этапе. В канале сводки игроки только слушают. Подключение добровольное, после нажатия кнопки; для микрофона необходимы HTTPS и разрешение браузера. Надёжность звука зависит от сети и VDO.Ninja.

Ядерную технологию можно разработать за 200 монет один раз в любом раунде. Строить ракеты по 300 можно начиная со следующего раунда после исследования, максимум одну за раунд и две в запасе. Удар выбирается без сведений о защите и состоянии чужого города; выстрел по уже разрушенному городу тоже расходует ракету. Награды и штрафы ведущего доступны на третьем этапе, результат видит страна-получатель.

Третий этап проходит даже в последнем раунде: ведущий сначала получает и оглашает сводку, затем отдельно завершает игру. После финала объявляется победитель, чужие панели остаются скрытыми. Старые публичные журналы экономики при загрузке фильтруются; для перехода от партии без отдельного ведущего начните новую партию.

## Колонист

Из каталога можно создать отдельную комнату на 3–4 участников. Ведущий добавляет до трёх ботов или зовёт друзей по коду. Боты действуют автоматически. После выхода игрока во время партии его место занимает бот.

В первой версии есть перемешиваемый остров из 19 участков, начальная расстановка, кубики, ресурсы, строительство, разбойник, карты развития, банк, порты и победа при 10 очках. Одно предложение между игроками обменивает один вид ресурса с каждой стороны, количество карт можно выбрать. Партия идёт без таймера хода.

## Админ-панель

После обновления сайта и регистрации своего аккаунта откройте PostgreSQL из каталога с Compose и назначьте роль владельца существующему аккаунту:

```sh
docker compose exec postgres psql -U kaban -d kaban
```

```sql
\prompt 'Логин владельца: ' owner_login
UPDATE accounts SET admin_role = 'owner'
WHERE username = lower(trim(:'owner_login'))
RETURNING username;
\q
```

Обновите профиль. Кнопка «Админ-панель» открывает `/admin`. Владелец выдаёт и отзывает доступ по логину, тестировщики запускают проверки. Для каждого запроса сервер проверяет действующую сессию и роль в PostgreSQL. После выдачи доступа тестировщику достаточно обновить профиль.

В разделе «Тестовое лобби с ботами» выберите режим и число ботов. Откроется обычный интерфейс лобби. Раскройте панель «Тестовая комната» и нажмите «Дать ход ботам», чтобы они заняли места, отметились готовыми или сделали доступные действия. В списке «Смотреть от лица» можно переключаться между ведущим и участниками одной партии. За выбранного игрока и за ведущего действия выполняются вручную.

Тестовые комнаты доступны создавшему их владельцу или тестировщику. Можно открыть до трёх комнат и вернуться в них из админ-панели. Комнаты живут в памяти до закрытия, перезапуска сервера или часа без активности. Камеры в них отключены.

Раздел «Автоматические проверки» по-прежнему показывает результат, проверенный сценарий и время выполнения для одного режима или всего каталога.

Официальные знаки для входа хранятся в `frontend/public/images`. Источники — [иконки VK](https://github.com/VKCOM/icons), [иконка Яндекс ID](https://id.yandex.ru/favicon.ico) и [пресс-кит Telegram](https://telegram.org/tour/screenshots).
