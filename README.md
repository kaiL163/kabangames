# KABAN GAMES

Игры для компании: интерфейс на React + Vite и React Router, сервер лобби на FastAPI. Сначала создайте лобби или войдите по коду, затем ведущий выбирает игру внутри лобби; участники переходят в неё автоматически. Ведущий создаёт комнату, игроки подключаются по четырёхбуквенному коду. В детективном деле «Последний сеанс» каждый участник может открывать общие улики, а ведущий отправляет итоговую версию. В остальных играх ведущий выбирает карточки и показывает ответы.

## Запуск через Docker

Нужны Docker Desktop и запущенный Docker Engine. В папке проекта:

```sh
docker compose up --build -d
```

Откройте http://localhost:8000. Чтобы игроки подключились с других устройств, откройте порт 8000 в локальной сети и используйте IP компьютера вместо localhost. Остановка: `docker compose down`. Посмотреть журнал: `docker compose logs -f`.

Для другого внешнего порта укажите переменную `PORT` перед запуском (например, `PORT=8080 docker compose up --build -d` в Linux/macOS или `$env:PORT=8080; docker compose up --build -d` в PowerShell).

## Быстрое размещение

Проект подходит для хостинга, который запускает Dockerfile. Загрузите папку проекта в репозиторий, создайте на выбранном хостинге веб-сервис из этого репозитория и выберите сборку по Dockerfile. Сервис слушает переменную `PORT` (если она не задана — 8000). Проверка доступности: `GET /api/health`. Настройте HTTPS и откройте выданный хостингом адрес. Конкретные шаги зависят от выбранного сервиса.

На VPS с установленным Docker можно скопировать проект на сервер и выполнить `docker compose up --build -d`. Для домена и HTTPS поставьте перед приложением обратный прокси. Комнаты сохраняются в подключённом Docker volume и восстанавливаются после перезапуска. Не удаляйте volume `kaban-data`: без него пропадут комнаты, пока они активны (неактивные комнаты удаляются через 6 часов). Один экземпляр приложения рассчитан на один VPS.

## Разработка без Docker

Терминал 1:

```sh
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload --port 8000
```

Терминал 2:

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес Vite из вывода команды. Запросы `/api` направляются на FastAPI. Сборка интерфейса: `npm run build` в папке `frontend`.

## Ограничения текущей версии

Максимум 16 участников в комнате. В лобби участники отмечают готовность, а ведущий ждёт всех перед запуском. Слово в «Крокодиле» показывается только ведущему. Закрытая или неактивная комната со временем удаляется, а комнаты сохраняются на диске и восстанавливаются при перезапуске сервера.

Детектив расширен до 20 материалов и пяти вопросов. Улики открываются по зависимостям (например, осмотр зала → экспертиза; камера и реестр → досмотр футляра). В блокноте можно сохранять личные заметки и получить подсказку. Три фотореалистичные иллюстрации созданы специально для вымышленного дела; карточки поддерживают увеличение снимков.


В разделе «Обсуждение» участники делятся версиями и аргументами. Каждый может изменить свою версию до окончания дела; после финала показаны ответы команды и правильные ответы. Личный блокнот остаётся на устройстве игрока.

Сетевые раунды: в восьми играх с вопросами каждый участник отвечает на своём устройстве, раунд длится до 30 секунд, а сервер начисляет очки. В «Закончи фразу» нужно минимум три участника: каждый пишет ответ, затем участники голосуют анонимно. За каждый голос автор получает 100 очков. Подключившиеся посреди раунда играют со следующего раунда. «Крокодил», «Правда или действие», «Две правды и одна ложь», «Безумный сценарист» и «Кто скорее?» поддерживают личные действия, ходы и голосование участников. В «Крокодиле» показывать жесты и говорить друг с другом нужно при личной встрече или через отдельный видеозвонок.


Добавлены «Шпион» (от четырёх участников: личные роли, вопросы, обсуждение и поиск шпиона) и «Реакция» (от двух участников: сигнал, ловушки и фальстарты). В шапке и вкладке используется оригинальный SVG-знак кабана. Одинаковые ники внутри комнаты запрещены.

В лобби и играх есть встроенная видеосвязь через VDO.Ninja: участник сам включает камеру с подтверждением, а постоянная панель остаётся подключённой при переходах между страницами. Для каждого лобби создаётся случайная комната с отдельным паролем. Микрофон отключён; для камеры нужен HTTPS и разрешение браузера; стабильность зависит от устройства, сети и VDO.Ninja.
